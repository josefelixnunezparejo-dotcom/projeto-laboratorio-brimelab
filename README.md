# Grupo Brimelab - Landing Page para Laboratorio Clínico 🔬🏥

Landing page moderna, responsiva y orientada a la conversión de clientes, desarrollada para **Grupo Brimelab** (Laboratorio Clínico). Incluye catálogo de estudios médicos, indicadores operativos y canales directos de contacto/agendamiento.

## 🚀 Tecnologías Utilizadas

- **HTML5 Semántico:** Estructura accesible con foco en SEO y usabilidad.
- **CSS3:** Diseño moderno con variables, Grid, Flexbox y animaciones fluidas.
- **JavaScript (ES6+):** Lógica interactiva para la navegación y elementos dinámicos.

## 💻 Características Principales

- 📱 Layout 100% responsivo para móviles y escritorio.
- 🧪 Muestrario interactivo de perfiles de exámenes (Hematología, Perfil Lipídico, Urinoanálisis, etc.).
- 📊 Sección de estadísticas dinámicas y tiempo de entrega de resultados.
- 💬 Integración directa con botón de contacto vía WhatsApp.
